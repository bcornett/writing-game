# Backlog — Dot's Writing Quest

Last updated: 2026-09-04

## Done

- Scaffolded on the kid-game framework (`~/Projects/flying-game/FRAMEWORK.md`):
  dev server with LAN detection and QR banner, service-worker generator with
  drift test, local CA for https on the LAN, PNG/QR encoders, update flow.
  Adapted for MP3 assets and rebranded.
- **62 glyphs** (0–9, a–z, A–Z) as stroke paths in kindergarten formation,
  with spoken names, stroke rhymes, and flip hints for the reversal-prone.
- **Tracer**: pure state machine — start on the dot, advance a few samples
  per move, no skipping, no running backwards; slips pause, resume continues.
- **Grader**: DTW over every stroke order/direction after bbox alignment,
  plus two-way coverage. Detects mirrored / flipped / turned twins, look-alike
  letters, drawn-from-the-wrong-end, dots on i/j, accidental taps. Thresholds
  pinned by tests over hundreds of synthetic drawings.
- **Progress model**: recency-weighted mastery, weighted picker that avoids
  repeats, stars → stickers (50), validated save file.
- **Curriculum**: twin pairs, spot/pop rounds from computed twins, six-step
  quest planning around the weakest glyph.
- **Voice**: 212 ElevenLabs clips (7,456 characters) generated by an
  idempotent, prioritised tool; manifest drift test; device-voice fallback;
  interruptible playback with time limits.
- **Screens**: home (with first-run name card and hold-to-open gear), trace
  (demo + three fading rounds), write (side-by-side result with flip-over
  animation), spot it, twins (with the bed trick), pop, quest, stickers,
  grown-ups panel (name, focus chips, settings, progress table, offline
  status, update button, QR of the page).
- Icons (Dot on a sunny gradient), manifest, iOS meta, safe-area layout,
  responsive rules for phones and landscape.
- 111 tests passing.

## Fixed after actually running it

- Level escalation between trace rounds jumped to level 3 because mastery
  was recomputed mid-session; now decided once per session.
- The pulsing start-dot ring scaled about the SVG viewport, not itself
  (`transform-box: fill-box`).
- Round line caps drew a stray dot at the end of a hidden (zero-length) dash;
  the hidden offset now overshoots the path by 2 units.
- Bubble text ran phrases together ("Let's write three Curve…"); fragments now
  get "…" or "." before the next line.
- An interrupted `voice.say()` never settled, so a screen awaiting it froze
  when the tab was backgrounded mid-sentence; playback is now interruptible
  and time-limited.
- The new-sticker overlay replaced the write result card; stars are now
  awarded before the card is shown.
- Result-pane labels overlapped the drawing; the flip animation also flipped
  the label.
- Spot-it cards sat left of centre.

## Dev notes

Synthetic finger for the console (on a trace screen):

```js
const { glyphStrokes } = await import('/src/render/glyphSvg.js');
const { resample, pathLength } = await import('/src/core/path.js');
const svg = document.querySelector('.trace-svg');
const fire = (type, [x, y]) => { const r = svg.getBoundingClientRect(); svg.dispatchEvent(new PointerEvent(type, { clientX: r.left + x / 100 * r.width, clientY: r.top + y / 100 * r.height, pointerId: 1, pointerType: 'touch', isPrimary: true, bubbles: true, cancelable: true, buttons: 1 })); };
for (const raw of glyphStrokes('5')) { const pts = resample(raw, Math.round(pathLength(raw) / 1.5)); fire('pointerdown', pts[0]); for (const p of pts) fire('pointermove', p); fire('pointerup', pts.at(-1)); }
```

screen the same way (`synthDrawing(glyph, rng, { transform: 'mirror' })`).
